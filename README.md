# 🗂️ StudyForge 3D - Flashcard Quiz App

A modern, clean, and interactive 3D Flashcard Quiz application designed for active recall and self-study. Built with React Native & Expo.

---

## ✨ Features
1. **Interactive 3D Flashcards:** 
   - Displays Question on the front and reveals Answer with a tactile 3D card elevation effect.
   - Includes a dedicated **"Show / Hide Answer"** toggle button as well as tap-to-flip functionality.
2. **Seamless Navigation:** 
   - Navigate back and forth through cards using **"Previous"** and **"Next"** buttons.
3. **Full Customization (CRUD):** 
   - **Add Card:** Create custom flashcards anytime with question and answer prompts.
   - **Edit Card:** Modify existing questions or answers instantly.
   - **Delete Card:** Remove mastered or unwanted flashcards from the deck.
4. **Clean & Modern UI:** 
   - Polished dark-mode theme with sleek typography and responsive layout.

---

## 🚀 How to Run the App Instantly (Live Demo)
To view and test this interactive app directly in your browser without local installation:
1. Open [Expo Snack](https://snack.expo.dev).
2. Copy the code from `App.js` in this repository.
3. Paste it into the `App.js` editor in Snack and switch to the **Web** or **Android** tab on the right to use the live app!
